Python for Data Science

Use Python, Pandas and Matplotlib to explore data, uncover patterns and build simple models. Eight weeks to practical, entry-level data science skills.

About this course

Start with the foundations of Python and learn how to turn raw data into useful insights. Work with realistic datasets, clean and analyse information, create visualisations, and build a small portfolio project.

This course is designed for learners who already know basic programming concepts or are comfortable learning them as they go. You will finish with a project you can discuss in interviews and share in your portfolio.

What you will learn

  • ✓Python fundamentals, variables, functions and working with files
  • ✓Explore and clean datasets using Pandas and NumPy
  • ✓Analyse data with grouping, filtering and summary statistics
  • ✓Create clear charts with Matplotlib
  • ✓Build a small data analysis project and explain your findings

Course curriculum

Module 1 · Python foundationsWeek 1

Variables, data types, conditions, loops, functions and reading files.

Module 2 · NumPy and PandasWeeks 2–3

Arrays, DataFrames, selecting rows, handling missing values, sorting and cleaning data.

Module 3 · Data analysisWeeks 4–5

Grouping, aggregation, joining datasets, descriptive statistics and asking useful questions.

Module 4 · VisualisationWeeks 6–7

Build and customise charts using Matplotlib, then communicate the main takeaways.

Module 5 · Portfolio projectWeek 8

Analyse a dataset from start to finish, document your approach and present your findings.
